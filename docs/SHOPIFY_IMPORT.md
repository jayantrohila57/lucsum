# Shopify catalogue import (LUCSUM)

This repo ships an **idempotent** import that replaces demo seed data with the 25 active Shopify products (5 styles × 5 colours), variants (S–XXL), inventory, collections, CMS pages/articles, and Shopify URL redirects.

## Export bundle

Place the Shopify Admin export JSON files under `data/shopify-export/` (committed in this repo for CI and local runs):

| File | Contents |
|------|----------|
| `products.json` | Active products (excludes 3 DRAFT legacy listings) |
| `variants.json` | Size variants, SKU, price, stock |
| `collections.json` | Style, colour, and catalogue collections |
| `content-misc.json` | Pages, blog articles, policies, menus, redirects |
| `content-text/` | Optional Markdown snapshots (not required for import) |

Override the directory with `SHOPIFY_EXPORT_DIR`.

## Database migrations

Run migrations **before** import (adds `catalog_collection`, `product_collection`, `site_page`, `subcategory.collection_slug`):

```bash
pnpm db:migrate
```

## Commands

```bash
# Soft-deactivate demo/seed data (products, categories, marketing, reviews, etc.)
pnpm purge-mock

# Same cleanup, invoked from the import script
pnpm shopify:import:cleanup

# Full import (default export path, skip Blob when token missing)
pnpm shopify:import

# Same, but no writes
pnpm shopify:import --dry-run

# Force Shopify CDN image URLs (no Vercel Blob upload)
pnpm shopify:import --skip-images
```

### Production (Jayant)

1. Merge the import PR and deploy (or run from a machine with production env).
2. Confirm `DATABASE_URL` is the **same** Neon database Vercel production uses.
3. **Recommended:** create a Neon branch from production, point `DATABASE_URL` at the branch, run migrate + import, smoke-test the store, then run the same commands against production.
4. Run:

```bash
export DATABASE_URL='postgresql://…'   # production or branch
export SHOPIFY_EXPORT_DIR=./data/shopify-export
# Optional: upload images to Blob (requires BLOB_READ_WRITE_TOKEN)
export BLOB_READ_WRITE_TOKEN='…'
pnpm db:migrate
pnpm shopify:import:cleanup
pnpm shopify:import --skip-images   # or omit flag when Blob is configured
```

5. Redeploy so `data/shopify-redirects.json` (regenerated by import) is picked up by `next.config.ts` redirects.

The import does **not** import customers, orders, or DRAFT legacy products.

## What gets written

- Categories: `t-shirts`, `collections`
- Subcategories: five style handles under `t-shirts`; colour/edit collections under `collections` (with `collection_slug` for membership queries)
- Products: one per Shopify product (colour), `live`, INR prices in paise
- Variants: S–XXL with inventory on warehouse `LUCSUM-SNP`
- `product_collection` rows for Shopify collection membership
- `site_page` rows for Shopify pages, policies, and blog articles
- `data/catalog-paths.json` and `data/shopify-redirects.json` for PDP paths and Next.js redirects

## Demo cleanup

`pnpm purge-mock` soft-deactivates demo data only: sets `deleted_at` / `is_active=false` / `status=archive` on non-catalogue products, soft-deletes non-`t-shirts`/`collections` categories and subcategories, deactivates `seed-marketing*` and picsum banners, unapproves seed reviews, deactivates seed discounts, cancels seed orders, and bans seed users. Safe to run multiple times.
